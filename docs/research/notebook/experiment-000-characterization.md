# RQ-003 Experiment 0B — Fundamental Measurement Dataset Characterization

## 1. Dataset overview

### Purpose and boundary

This notebook characterizes the unlabeled measurement artifact generated by
RQ-003 Experiment 0. It describes instrumentation, representation, coverage,
and data quality only. It does not inspect finalized outcomes, correlate any
measurement with an outcome, estimate predictive value, rank measurements,
construct derived measurements, execute a Strategy, or perform evaluation.

The governing sources are:

- [RQ-003](../questions/RQ-003-winning-square-predictability.md);

- the Experiment 0 generator in
  [`rq003_experiment0.py`](../../../src/orev3/datasets/rq003_experiment0.py).

### Method

The analysis streamed the generated JSONL once and checked every record for:

- the exact four-field Experiment 0 schema;
- canonical JSON serialization;
- lowercase 64-character SHA-256 identity syntax;
- exactly eight ordered unsigned-integer values;
- candidate blocks ordered `0` through `24` for every decision;
- one shared decision identity per 25-candidate block; and
- consistency of context-wide values across all candidates in a decision.

Descriptive summaries were computed without loading or consulting
`finalized_outcome`, RFC-012 evidence, labels, or evaluation results.

### Canonical encoding and identity consistency

All eight measurements passed the same generation-time controls:

1. the deterministic pipeline validated each definition, eligibility decision,
   protocol dependency, revision dependency, and executable binding;
2. each produced `MeasurementVector` was canonically encoded, reconstructed,
   compared for equality, and only then persisted; and
3. the persisted ordered values passed the Experiment 0 unsigned-64-bit and
   fixed-length schema validation.

The generated file contained no noncanonical JSON rows, invalid identity
strings, malformed value arrays, or output-order deviations. The reduced
Experiment 0 record intentionally persists the vector identity and ordered
values rather than the complete canonical `MeasurementVector` identity
material. Consequently, generation proves canonical vector reconstruction,
while post-hoc inspection of this reduced artifact can verify identity syntax,
uniqueness, ordering, and deterministic regeneration but cannot independently
reconstruct a vector identity without replaying the pipeline.

## 4. Unexpected observations

1. **Three measurements are constant zero.** Active-Round motherlode,
   pre-finalization total vaulted, and legacy pre-finalization total winnings
   contain one distinct value. The constant Active-Round value is an explicit
   pre-finalization invariant. The two aggregate constants also match the
   frozen values actually published in this retained revision. This is a
   dataset characteristic, not missingness.
2. **One deployed-lamport value is much larger than the rest.** Square 22 has
   one value of 4,264,350,439 lamports; the next-largest value in the dataset is
   1,614,874,593 lamports on square 24. Both are valid unsigned integers. The
   reduced output does not carry a replay round identifier, so source tracing
   requires deterministic identity reconstruction against replay.
3. **Decision-point age is usually small but has a long tail.** There are
   18,590 selections at most two slots before the requested target and 61 that
   are at least three slots before it. The maximum distance is 145 slots.
4. **Two source rounds cannot produce Experiment 0 decisions.** Both are
   `partial_start` lifecycles whose first observation occurs after the
   requested decision boundary. They are excluded rather than fabricated.
5. **Production-cost EMA changes at every retained decision point.** All
   18,651 decision observations have distinct published values. This statement
   records cardinality only and does not interpret the aggregate.

## 5. Potential data-quality concerns

### Replay coverage

The 739 eligible partial lifecycles and the long tail in decision-point age
mean that the generated decisions are structurally valid but do not all have
equivalent lifecycle coverage or cadence. RQ-003 requires those controls to
remain explicit in later scientific work. The two post-boundary-only rounds
must remain exclusions unless a separately governed decision rule establishes
an eligible pre-boundary observation.

### Audit traceability

The intentionally narrow Experiment 0 record does not persist round identity,
source observation identity, source dataset identity, selection distance,
protocol revision, or generation configuration. These values are correctly
excluded from the measurement vector, but the generated artifact by itself is
not a complete audit manifest. A decision identity can be traced only by
reconstructing identities from the replay source.

### Independent identity verification

The artifact persists `measurement_vector_identity` and ordered values but not
the remaining canonical identity material. The generator reconstructed every
full vector before persistence, and deterministic regeneration tests the whole
execution path. Post-hoc consumers of the reduced file, however, cannot
independently recompute the vector identity from that file alone. This is an
instrumentation limitation, not evidence of an identity failure.

### Revision-scoped constants

The three constant-zero measurements are valid direct observations under the
supported revision. Before datasets from another revision are combined or
compared, RFC-014 eligibility and semantic-compatibility controls must prevent
the zero-valued legacy meanings from being silently pooled with successor
fields or substituted values.

### Range anomaly trace

The square-22 deployed-lamport maximum is valid under current type and protocol
range checks but is sufficiently separated from the remaining observed range
to warrant provenance tracing. This analysis does not label it erroneous or
remove it.

No unexpected null, non-integer, negative, overflow, schema, canonicalization,
identity-format, candidate-order, or context-replication inconsistency was
found.

## 6. Recommendations before Experiment 1

These recommendations concern instrumentation and auditability only. They do
not approve derived measurements, Feature Sets, baselines, ranking procedures,
models, or Strategies.

1. Record a deterministic audit manifest alongside a generated artifact. It
   should bind the source dataset hash, decision configuration identity,
   protocol revision, output schema and order, record count, and artifact
   digest without adding any of those audit fields to measurement input.
2. Provide a read-only provenance index that maps decision identities to replay
   round and source-observation identities, lifecycle coverage, and selection
   distance. This would permit source verification of the two exclusions, the
   long-tail decision points, and the square-22 range anomaly without changing
   the Experiment 0 payload.
3. Make the distinction between generation-time full-vector reconstruction
   and post-hoc reduced-record validation explicit in future experiment
   protocols. If independent artifact-only identity reconstruction is a
   requirement, that requirement needs separate instrumentation design.
4. Preserve cadence, lifecycle coverage, and revision provenance as validation
   controls. They must remain audit or stratification information and must not
   enter `DecisionContext`, measurement values, or Strategy input.
5. Document expected constant-field behavior per supported revision before
   scientific comparisons, while retaining the exact observed values.

Additional instrumentation work recommended before Experiment 1.
