# Evaluation Architecture

Evaluation determines whether a candidate is useful as a miner.

Minimum metrics:

- deploy count,
- deployed SOL,
- returned SOL,
- ORE earned,
- transaction fees,
- failed transaction cost,
- net SOL change,
- marked and realized economic value,
- hit rate,
- ROI,
- drawdown,
- losing streak,
- capital utilization,
- performance by time segment and regime.

Evaluation must distinguish backtest, paper, controlled-live, and production
results.
