# Release Process

## Research Artifact

1. Ratified RFC.
2. Implementation and tests.
3. Generated report.
4. Review and conclusion.
5. Journal entry where the result changes direction.

## Candidate Miner

1. Supporting report.
2. Walk-forward evaluation.
3. Economic and risk review.
4. Paper release.
5. Controlled-live release.
6. Wallet reconciliation.
7. Production promotion decision.

Every release must identify the dataset, code revision, configuration, and
capital limit.
