# Research Analyses

This directory organizes reproducible machine-generated analysis artifacts by
domain:

- `baseline/`
- `datasets/`
- `economics/`
- `features/`
- `strategy/`
- `validation/`

Generated contents remain local and are ignored by Git. Historical manifests
and reports may retain their original input and output paths as immutable
provenance; those values are not repository navigation links.

Human-readable conclusions belong under
[`docs/research/`](../../../docs/research/README.md).
